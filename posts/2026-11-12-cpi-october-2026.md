소비자물가지수는 국가데이터처가 매달 초 발표해요. 가구가 많이 사는 품목 수백 개의 가격을 소비 비중대로 묶어서, **1년 전 같은 달과 비교**한 값이 우리가 뉴스에서 보는 '물가 상승률'이에요.

## 1. 10월 물가 핵심 숫자

| 지표 | 1년 전 대비 | 한 달 전 대비 |
|---|---|---|
| 소비자물가 (전체) | **2.8%** | 0.2% |
| 근원물가 (식료품·에너지 제외) | 2.8% | 0.4% |
| 근원물가 (농산물·석유류 제외) | 2.8% | 0.4% |
| 생활물가 (자주 사는 품목) | 2.6% | 0.1% |
| 신선식품 | **-6.2%** | -3.8% |

올해 흐름을 보면 5~6월 3%대에서 7월 2.8%, 8월 3.1%, 9월 2.9%, 10월 2.8%로 **2%대 후반에서 오르내리고 있어요.**

## 2. 내린 것 vs 오른 것

| 내린 품목 | 상승률 | 오른 품목 | 상승률 |
|---|---|---|---|
| 채소 | -11.2% | 경유 | 19.7% |
| 과실 | -8.4% | 등유 | 19.0% |
| 농산물 전체 | -7.5% | 휘발유 | 11.6% |
| 농축수산물 전체 | -1.7% | 석유류 전체 | 14.9% |
| | | 즉석식품 | 12.4% |
| | | 수산물 | 5.4% |
| | | 축산물 | 4.8% |
| | | 가공식품 | 2.9% |
| | | 외식 | 2.9% |

채소와 과일은 작황이 좋고 가을 출하가 늘어 크게 내렸어요. 하지만 고기·생선은 올랐고, 빵·비스킷(각 5.9%)과 즉석식품 같은 가공식품은 출고가 인상과 명절 할인 종료로 오름폭이 커졌어요.

## 3. 숫자는 낮아졌는데 체감은 왜 비쌀까

이유는 **기여도**에 있어요. 전체 2.8% 가운데 석유류가 **0.56%p**, 외식이 **0.42%p**를 끌어올렸어요. 반대로 농축수산물은 **0.14%p**를 끌어내렸어요.

| 체감이 큰 이유 | 설명 |
|---|---|
| 매일 사는 품목이 올랐다 | 기름, 외식, 가공식품은 자주 사요 |
| 내린 품목은 비중이 작다 | 채소·과일은 소비 비중이 상대적으로 작아요 |
| 물가는 '오른 수준'에서 또 오른다 | 상승률이 낮아져도 가격이 내려가는 건 아니에요 |

예를 들어 한 달에 기름값 20만원을 쓰는 집이라면, 1년 전 같은 양을 넣을 때보다 석유류 평균 상승률 14.9% 기준 약 **2만 6천원**을 더 쓰는 셈이에요(20만원은 올해 가격, 1년 전 가격은 20만 ÷ 1.149 ≈ 17만 4천원).

## 4. 석유 최고가격제는 얼마나 효과가 있었나

정부는 국제유가 급등에 대응해 올해 3월 석유 최고가격제를 도입했어요. 정부 추산으로는 이 제도가 10월 물가 상승률을 **0.8%p** 낮췄어요. 제도가 없었다면 10월 상승률이 **3.6%** 였을 거라는 뜻이에요.

| 쟁점 | 내용 |
|---|---|
| 효과 | 물가 상승률을 약 0.8%p 낮춤 (정부 추산) |
| 부담 | 장기화되면서 재정 부담과 수요 관리 공백 우려 |
| 해제 시 | 휘발유 리터당 100원 이상 오를 수 있다는 전망 |
| 정부 입장 | 해제에 신중, 김장철 농축산물 할인에 440억원·수산대전 200억원 투입 |

## 5. 앞으로 볼 것: 내 지갑과 금리

한국은행은 근원물가 오름세가 높아 **11월 물가도 2%대 후반**이 이어질 것으로 봤어요. 근원물가가 2.8%로 물가안정목표(2%)보다 높은 상태라, 이번 숫자는 **11월 26일 기준금리 결정**에서도 중요하게 다뤄질 수 있어요.

| 날짜 | 일정 | 내 생활과의 연결 |
|---|---|---|
| 11월 26일 | 한국은행 기준금리 결정 | 대출·예금 금리 |
| 12월 초 | 11월 소비자물가 발표 | 김장·난방비 부담 |
| 미정 | 석유 최고가격제 조정 여부 | 기름값 |

물가가 2.8%일 때 연 3% 예금은 이자소득세 15.4%를 떼면 세후 약 2.54%라서, 물가를 따져 보면 실제 구매력은 오히려 조금 줄어요. 실질 금리 계산은 [적금 이자 계산법](/posts/savings-interest-real-rate.html)에서, 금리 인상 때 대출 이자 변화는 [기준금리 0.25%p 오르면 내 대출 이자는](/posts/base-rate-hike-loan-interest.html)에서 확인해 보세요.
