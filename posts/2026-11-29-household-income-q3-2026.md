가계동향조사는 국가데이터처(옛 통계청)가 전국 가구의 소득과 지출을 분기마다 조사하는 통계예요. 2026년 11월 26일 3분기(7~9월) 결과가 나왔어요. 아래 숫자는 모두 1인 이상 전체 가구의 월평균이고, 증감률은 1년 전(2025년 3분기)과 비교한 거예요.

## 1. 소득: 늘었는데 줄었다?

| 항목 | 월평균 금액 | 1년 전보다 |
|---|---|---|
| 전체 소득 (명목) | **548만원** | +0.8% |
| 실질소득 (물가 반영) | - | **-2.1%** |
| 근로소득 | 348만 7천원 | +3.6% |
| 사업소득 | 97만 5천원 | -1.4% |
| 이전소득 | 84만 5천원 | -8.5% |
| └ 공적이전소득 | 62만 9천원 | **-15.4%** |
| └ 사적이전소득 | 21만 6천원 | +20.4% |
| 재산소득 | - | -11.1% |

- 0.8% 증가는 2023년 2분기 이후 가장 작은 증가폭이에요.
- 가장 큰 원인은 **공적이전소득** 감소예요. 작년 3분기에는 민생회복 소비쿠폰이 지급돼 공적이전소득이 40% 넘게 늘었는데, 올해는 그 돈이 없으니 크게 줄어 보이는 거예요(기저효과).
- 일해서 버는 **근로소득은 3.6%** 늘어 2분기(0.8%)보다 나아졌어요. 반면 **사업소득은 1.4%** 줄었는데, 원재료·포장재 값과 이자 부담이 자영업자 소득을 깎은 것으로 풀이돼요.

## 2. 지출: 소비보다 세금·이자가 더 늘었어요

| 항목 | 월평균 금액 | 1년 전보다 |
|---|---|---|
| 가계지출 | 420만 4천원 | +5.1% |
| 소비지출 | 303만원 | +2.9% (실질 0.0%) |
| 비소비지출 | 117만 4천원 | **+11.0%** |
| └ 경상조세 (세금) | 32만 1천원 | +8.0% |
| └ 연금기여금 | 15만 8천원 | +7.8% |
| └ 사회보험료 | 18만 9천원 | +3.4% |
| └ 이자비용 | 14만 7천원 | **+11.0%** |
| └ 가구 간 이전지출 | 24만 2천원 | +30.0% |

비소비지출 증가폭(11.0%)은 5년 만에 가장 커요. 근로소득이 늘면서 소득세도 늘었고, 대출 금리가 오르면서 **이자비용이 11.0%** 늘었어요. 올해 기준금리가 세 차례 오른 영향이 가계부에도 찍히기 시작한 셈이에요. 기준금리 인상 배경은 [기준금리 3.25% 인상 글](/posts/base-rate-hike-325-november-2026.html)에서 정리했어요.

소비지출 안에서 많이 늘고 줄어든 항목은 이래요(명목 기준).

| 많이 늘어난 항목 | 증감 | 줄어든 항목 | 증감 |
|---|---|---|---|
| 교통·운송 (자동차 구입 +34.6%) | +9.6% | 의류·신발 | -4.6% |
| 정보통신 | +7.5% | 주류·담배 | -4.0% |
| 주거·수도·광열 | +4.9% | 교육 | -2.4% |
| 보건 | +4.1% | | |
| 식료품·비주류음료 (육류 +15.1%) | +3.3% | | |

소비지출은 2.9% 늘었지만 물가를 빼면 **0.0%**, 사실상 제자리예요. 돈은 더 썼는데 산 물건의 양은 그대로라는 뜻이에요. 장바구니 물가 흐름은 [10월 소비자물가 글](/posts/cpi-october-2026.html)에서 볼 수 있어요.

## 3. 쓰고 남는 돈은 11.2% 줄었어요

| 항목 | 금액 | 1년 전보다 |
|---|---|---|
| 처분가능소득 (소득 - 비소비지출) | 430만 6천원 | **-1.7%** |
| 흑자액 (처분가능소득 - 소비지출) | 127만 6천원 | **-11.2%** (-16만 1천원) |
| 흑자율 | 29.6% | 32.8% → 29.6% |
| 평균소비성향 | 70.4% | +3.2%p |

처분가능소득은 세금·보험료·이자를 내고 실제로 쓸 수 있는 돈이에요. 이게 줄어든 건 13분기 만이에요. 흑자액, 즉 저축이나 빚 상환에 쓸 수 있는 여윳돈은 한 달에 16만원 넘게 줄었어요. 평균소비성향 70.4%는 쓸 수 있는 돈 100원 중 70원을 소비에 썼다는 뜻이에요.

## 4. 소득 하위 20%는 더 어려워졌어요

| 구분 | 1분위 (하위 20%) | 5분위 (상위 20%) |
|---|---|---|
| 월평균 소득 | 127만 7천원 (**-2.7%**) | 1,174만 6천원 (+1.4%) |
| 근로소득 | 24만 8천원 (-9.2%) | 833만원 (+4.9%) |
| 처분가능소득 | 106만 5천원 (-5.4%) | - |
| 소비지출 | 140만 8천원 (+1.6%) | - |
| 월 적자 | **34만 4천원** (+32.1%) | - |

- 1분위는 다섯 분위 중 유일하게 소득과 근로소득이 모두 줄었어요. 일하는 가구가 줄고 임시·일용직 비중이 커진 영향이에요.
- 1분위의 평균소비성향은 132.3%로, 버는 돈보다 쓰는 돈이 많아 매달 적자예요.
- 상위 20%와 하위 20%의 소득 차이를 보여 주는 **5분위 배율**(균등화 처분가능소득 기준)은 5.07배에서 **5.39배**로 커졌어요.
- 2분위는 소득 증가율(1.7%)이 가장 높았지만, 비소비지출이 17.5% 늘어 흑자액이 17.7% 줄었어요.

## 5. 내 지갑에는 어떤 신호일까

- **이자 부담은 계속 커질 수 있어요.** 기준금리가 11월에 다시 올랐기 때문에 4분기 이자비용은 더 늘 가능성이 커요. 변동금리 대출이 있다면 금리가 0.5~1%p 더 오를 때 월 상환액을 미리 계산해 두세요.
- **성장률과 내 살림은 다르게 움직여요.** 한국은행은 올해 성장률을 3.9%로 올렸지만, 반도체 이익이 가계 소득으로 퍼지기까지는 시간이 걸려요. 이번 통계는 그 간격을 숫자로 보여 줘요.
- **하위 소득 가구는 지원 제도를 챙길 때예요.** 기준중위소득 이하라면 겨울철 긴급복지·에너지바우처 같은 제도를 확인해 보세요. 기준은 [2027 기준중위소득 글](/posts/median-income-2027-basic-livelihood.html)에 정리했어요.

4분기 가계동향은 2027년 2월쯤 발표돼요. 이번에 빠진 소비쿠폰 기저효과가 사라지면 소득 흐름이 더 정확하게 보일 거예요.
